新版简历：
BuyPilot-AI-自研多模态电商导购 Agent
后端与 Agent 核心开发
项目地址：https://github.com/Red-Bean-Bun/BuyPilot-AI

技术栈：Python FastAPI + PostgreSQL/pgvector + asyncio + SSE + 百炼 Qwen / Doubao + jieba + BM25 + Docker Compose

项目简介：基于 RAG 的多模态电商智能导购 Agent，字节跳动 AI 全栈挑战赛参赛项目（3 周 / 3 人）。后端自建 Agent 管道，完成意图路由、购买标准生成、混合检索、流式推荐、多轮状态与评测闭环；支持文字 + 图片输入，覆盖美妆/数码/服饰/食品 4 大品类，4 条 Demo 链路端到端跑通。离线评测覆盖 20 条样本、15 项指标，验收综合分 78.4%。

功能描述：
设计五阶段 Agent 管道（意图→标准→检索→推荐→决策），阶段间通过结构化模型解耦，可独立替换和测试。采用“确定性规则 + LLM”分层意图路由，预算调整、换一组、加购等明确表达优先走规则，模糊表达再调用 LLM；图片分析、反馈读取与文本处理使用 asyncio 并发编排

基于意图阶段提取的品类、预算等约束构造投机 Criteria，提前启动检索，使 pgvector 查询与正式 Criteria 生成并行；完整标准返回后对候选集执行内存二次过滤，不满足时回退正式 Criteria 串行检索，在保证约束一致性的同时缩短首卡等待时间

构建“语义召回→硬约束复核→关键词增强→Rerank 精排→证据绑定”链路；pgvector 匹配“油皮→控油”等语义关系，BM25/RRF 增强品牌、型号等精确词排序，Python 复核预算、品类和排除项。无结果时渐进放宽预算，品类与商品类型不退让。

推荐理由绑定命中 Chunk 原文；通过候选商品校验和 23 项禁止词过滤拦截库存、包邮、优惠券等不可验证声明；价格异常时追加纠偏提示。

SSE 推送 10 种结构化事件，耗时阶段每 0.8s 检查取消并发送 thinking 心跳；已输出文本后失败不重试。模块加载时校验事件类型与 JSON Schema，不一致则阻止启动。

多轮对话继承历史 Criteria，用户只需说“预算降到 200”即可复用肤质等约束；品类切换时清理品牌和商品类型，保留预算等通用条件。用户反馈持久化并注入后续 Criteria、检索和决策，形成闭环。
