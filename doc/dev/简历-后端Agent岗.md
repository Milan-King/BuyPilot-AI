BuyPilot-AI-自研多模态电商导购 Agent                                                                    
后端开发
项目地址：https://github.com/Red-Bean-Bun/BuyPilot-AI

技术栈：Python FastAPI + PostgreSQL/pgvector + asyncio + SSE + 百炼 Qwen / Doubao + jieba + BM25 + Docker

项目简介：基于 RAG 的多模态电商智能导购 Agent，字节跳动 AI 全栈挑战赛参赛项目（3 周 / 3 人）。后端自建 Agent 管道编排，完成意图路由、标准生成、混合检索、流式推荐、多轮对话评测闭环。支持文字 + 图片多模态输入，覆盖美妆/数码/服饰/食品 4 大品类，4 条 Demo 路径全部端到端跑通。

功能描述：
设计五阶段 Agent 管道（意图→标准→检索→推荐→决策），各阶段可独立替换和测试。意图识别用规则拦截 80% 以上固定模式输入，< 1ms 命中，只有模糊句子才调 LLM。支持文字和图片双模输入，图片经视觉模型提取关键信息后与文字意图合并，图片和文本向量并行检索，全链路 asyncio 并发

LLM 生成购买标准需要1.5~3 秒，不等 LLM 生成完整购买标准，用意图阶段已拿到的品类、预算等中间结果提前发起检索和 LLM 推理在时间上重叠。LLM 完成后用完整标准做一次轻量筛查即可，无额外 I/O。实测首张推荐卡延迟从约７秒降到约 3 秒，检索失败时自动回退串行，不影响可用性

检索分五层递进，首层 SQL 硬过滤卡住预算、品类等刚性条件，避免"200 元预算"被语义漂移到 198 元商品。向量和关键词两路并行召回互补，向量抓"油皮→控油"这类概念关联，关键词兜底品牌名、型号等专有名词，融合后由精排模型统一打分。无结果时自动放宽预算重试，品类不退让。

推荐理由绑定知识库原文可溯源；23 项禁止词过滤拦截"库存""包邮""优惠券"等模型倾向编造的不可验证声明；价格数字与数据库真实值交叉比对，不一致即纠正。

SSE 流式推送 10 种事件类型，LLM 等待期间每 0.8s 发心跳保活。已推送内容后失败不重试，避免客户端收到重复文本。启动时自动校验前后端事件协议，不一致阻止启动。

多轮对话自动继承上轮约束，用户说"预算降到 200"不用重复"油性肤质"。检测到话题切换时（从洗面奶跳到手机）清空品牌和产品类型约束，预算等通用条件保留。用户反馈持久化并注入下轮检索，形成反馈闭环。
